# Linux incident checklist
- [ ] Record UTC start, impact, scope and recent changes.
- [ ] Confirm SSH identity, host and privileges.
- [ ] Check service status and recent journal; preserve evidence before restarting.
- [ ] Identify process, CPU interval, memory available, load and file handles.
- [ ] Compare device, partition, filesystem, bytes, inodes and quotas.
- [ ] Check listeners, endpoint, DNS, TCP and authenticated database access separately.
- [ ] Correlate request IDs and timestamps across application and database.
- [ ] Select minimal mitigation with rollback; validate business recovery.
- [ ] Package reviewed evidence and communicate remaining uncertainty.
